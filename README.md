# Signatures mail ANEKDOTE / DBM — version Gmail

Dix signatures HTML de **400 px de large** (123 px de haut, ombre comprise), classées par Nom-Prénom. Les textes, le séparateur, le fond blanc et l’ombre sont en HTML ; seuls les logos sont des images.

## Installer dans Gmail

1. Ouvrir `index.html` dans un navigateur avec une connexion Internet.
2. Cliquer sur **Copier la signature** pour la personne concernée.
3. Dans Gmail : Paramètres > Voir tous les paramètres > Général > Signature. Effacer l’ancienne signature, puis coller la nouvelle.
4. Enregistrer les modifications. Ne pas coller le code HTML comme du texte.

Les deux logos utilisent les fichiers d’origine **déjà disponibles publiquement** dans le dépôt GitHub. Les URL ont été vérifiées avec une réponse HTTP 200. Aucune publication supplémentaire n’est nécessaire pour que les logos s’affichent. Le retrait visuel des marges transparentes du logo ANEKDOTE est compensé par les dimensions et espacements des tableaux, sans modifier l’image distante.

Gmail ne prend pas en charge `box-shadow`. L’effet d’ombre est donc reproduit par quatre bandes de 1 px, du gris clair au blanc, à droite et en bas. Il reste en HTML/CSS et ne dépend d’aucune image supplémentaire. C’est une approximation de l’ombre floutée du navigateur.

Mesures conservées : séparateur à 173 px du bord gauche, haut à 18 px, hauteur 84 px ; début des textes à 188 px ; logo DBM à 18 px du bord gauche. La largeur totale, ombre comprise, est 400 px. Typographie Arial/Helvetica. Téléphones et adresses email cliquables.

Les coordonnées et fonctions correspondent à la liste fournie. Louise Petit et Louana Brunel ont le même numéro dans cette liste.

La mise en page et le chargement des logos ont été vérifiés dans Chromium. Le collage dans Gmail doit encore être vérifié dans une session réelle.
